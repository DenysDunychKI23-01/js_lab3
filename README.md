Ознайомитися з поняттям функції, видами функцій (`Function Declaration`, `Function Expression`, `Arrow Functions`), принципами їх оголошення, виклику та використанням у програмі. ## 📋 Короткий опис виконаних завдань

### 🟢 Рівень 4–6 балів
1. **Персональне привітання:** Використання окремих функцій `getFullName` та `showGreeting` для формування та виведення даних.
2. **Оцінка студента:** Конвеєр функцій `getStudentInfo`, `checkGrade` та `showStudentResult` для текстової інтерпретації оцінки.
3. **Обчислення чайових:** Функція `calculateTip` з параметром за замовчуванням (10%) та підсумковий розрахунок.

### 🟡 Рівень 7–9 балів
1. **Таймер з колбеком:** Асинхронний виклик `startGreetingTimer` з передачею стрілкової функції як колбека.
2. **Калькулятор:** Функція `calculate(a, b, operation)` з обробкою базових арифметичних операцій та перевіркою на нуль.
3. **Замикання (Closure):** Функція `createClickCounter()`, яка зберігає стан лічильника `count` між викликами.

### 🔴 Рівень 10–12 балів
1. **Генератор випадкових чисел:** `function* randomGenerator` з нескінченним циклом `while(true)` та покроковим отриманням значення через кнопку.
2. **Генератор паролів:** Використання `next(value)` для передачі символів назад у генератор та формування готового пароля.
3. **Генератор діалогів (Чат-бот):** Покрокова розмова через `chatBot()`, де відповіді користувача впливають на наступні кроки `yield`.
4. **Контекст `this` та `bind()`:** Виправлення втрати контексту методу об'єкта при призначенні його обробником події кнопки.
